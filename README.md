# Cleo Code — тестовые сборки

Сборки Cleo Code 2 для тестирования. Скачайте файл из раздела [Releases](https://github.com/iforaa/CleoCode-Releases/releases).

- Mac на Apple Silicon (M1 и новее): `cleocode-mac-arm64.dmg`
- Mac на Intel: `cleocode-mac-x64.dmg`

Откройте образ и перетащите Cleo Code в «Программы». Приложение обновляется само.
